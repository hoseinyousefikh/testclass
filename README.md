# Karvand Manager

Karvand Manager is a simple Python project for managing Karvand information and storing data in a JSON file.

## Features

* Add a new Karvand
* Show the list of Karvands
* Edit Karvand information
* Delete a Karvand
* Show a general report
* Store all information in a JSON file
* Automatically create the JSON file when the program runs

## Karvand Information

Each Karvand has the following information:

* Full name
* Email
* City
* Education
* Skills

## Technologies

* Python
* JSON

## How to Run

Run the following command:

```bash
python main.py
```

The program provides a simple menu for managing Karvands.
